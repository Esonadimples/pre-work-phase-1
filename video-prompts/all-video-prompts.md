# Vertical Video Prompts: All Four Scripts
Every prompt below is paste-ready: the script's style block is already appended. Each is a 5-8 second clip, 9:16. Faces are kept out of frame so characters stay consistent across clips. Add captions and the on-screen emphasis text in your editor, and record the voiceover yourself.
The final shot of each script (signature) is not generated: use an end card or film yourself on camera.
